Installer RegieWave

Gratuit. Tout ce dont le logiciel a besoin est inclus : FFmpeg, Chromium pour les pages web, et le reste.

Choisissez « pour tous les utilisateurs » (conseillé : caméra virtuelle comprise) ou « pour moi seulement » (sans droits d'administrateur). L'installateur n'est pas encore signé : SmartScreen peut demander « Informations complémentaires » puis « Exécuter quand même ».

Un seul fichier, sans installation : rendez-le exécutable (chmod +x) puis lancez-le. PipeWire, Vulkan et les pilotes graphiques sont ceux de l'ordinateur. Sans FUSE : lancez-le avec --appimage-extract-and-run.

Vérifier le fichier

Comparez l'empreinte SHA-256

L'empreinte ci-dessus est celle donnée par GitHub. Si le résultat de la commande est différent, ne lancez pas le fichier.

Windows (PowerShell)

Get-FileHash .\RegieWave-*-installation.exe -Algorithm SHA256

Linux

sha256sum RegieWave-*-x86_64.AppImage
Ensuite

Mises à jour et versions

Mises à jour (Windows)

Dans RegieWave : Outils → Mises à jour. Le fichier est téléchargé, vérifié par son empreinte SHA-256, puis installé, en gardant la version précédente pour y revenir.

Mises à jour (Linux)

Téléchargez la nouvelle AppImage et remplacez l'ancienne. Vos projets restent où ils sont.

Anciennes versions

Toutes les versions sont sur la page GitHub. Un projet ouvert dans une version plus récente ne s’ouvre plus dans une plus ancienne : gardez une copie.

Version alpha. RegieWave est encore en développement : beaucoup de fonctions n'ont été essayées que sur un seul ordinateur, pas encore avec tous les modèles de webcams, micros, cartes graphiques et services de diffusion. Faites un essai avant un direct ou un enregistrement important, gardez une copie de vos projets et signalez les problèmes : c'est ce qui fait avancer le logiciel.
