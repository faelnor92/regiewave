Pour toute question, demande ou signalement concernant le site ou le logiciel : sur la page des tickets GitHub.

OBS, Twitch, YouTube, Kick et les autres noms cités sont des marques de leurs propriétaires. RegieWave n’est affilié à aucun d’eux.

4. Données personnelles et cookies

Ce site ne dépose aucun cookie, n’utilise ni statistiques de visite, ni publicité, ni police, image ou script venant d’un autre serveur, et n’a ni compte ni formulaire.

  • Votre navigateur garde seulement, sur votre appareil, la langue que vous avez choisie (clé rw-lang). Elle n’est jamais envoyée à personne et s’efface avec les données du site.
  • L’assistant (la mascotte) fonctionne entièrement dans votre navigateur : vos questions ne sont envoyées à personne et ne sont pas conservées. Il note seulement, le temps de l’onglet (stockage de session), si la visite guidée est en cours, si sa bulle d’accueil a déjà été montrée et où vous avez déplacé la mascotte.
  • Comme pour tout site web, le serveur d’hébergement (GitHub) reçoit des données techniques de connexion, dont votre adresse IP. Leur traitement relève de la politique de confidentialité de GitHub.
  • La page « Télécharger » interroge GitHub (api.github.com) depuis votre navigateur pour afficher la dernière version publiée ; GitHub reçoit alors votre adresse IP. Sans réponse, la page reste utilisable.
  • Le logiciel RegieWave n’envoie aucune donnée à son auteur. Il se connecte seulement aux services que vous choisissez (Twitch, YouTube…) et, si vous le demandez, à GitHub pour chercher une mise à jour.

L’éditeur ne conservant aucune donnée personnelle sur les visiteurs, il n’y a rien à consulter, rectifier ou supprimer de son côté. Pour les données traitées par GitHub, vos droits (accès, rectification, effacement…) s’exercent auprès de GitHub : support.github.com/contact/privacy. En France, vous pouvez aussi saisir la CNIL.

5. Responsabilité

Les informations de ce site sont données de bonne foi et peuvent évoluer. RegieWave est une version alpha, fournie sans garantie : faites un essai avant un direct ou un enregistrement important et gardez une copie de vos projets. L’éditeur n’est pas responsable du contenu des sites vers lesquels ce site renvoie.
