A single file, no install: make it executable (chmod +x) then run it. PipeWire, Vulkan and graphics drivers come from your computer. Without FUSE: run it with --appimage-extract-and-run.

Verify the file

Compare the SHA-256 fingerprint

The fingerprint above is the one GitHub gives. If the command's result differs, do not run the file.

Windows (PowerShell)

Get-FileHash .\RegieWave-*-installation.exe -Algorithm SHA256

Linux

sha256sum RegieWave-*-x86_64.AppImage
Afterwards

Updates and versions

Updates (Windows)

In RegieWave: Tools → Updates. The file is downloaded, checked against its SHA-256 and installed, keeping the previous version so you can go back.

Updates (Linux)

Download the new AppImage and replace the old one. Your projects stay where they are.

Older versions

All versions are on the GitHub page. A project opened in a newer version no longer opens in an older one: keep a copy.

Alpha version. RegieWave is still in development: many features have only been tried on a single computer, not yet with every webcam, microphone, graphics card and streaming service. Test before an important live show or recording, keep a copy of your projects and report problems : that is what moves the software forward.
