Tout ce qui s'ajoute à RegieWave sans venir de lui est réuni dans une seule fenêtre : Outils → Extensions. C'est l'équivalent du gestionnaire de plugins d'OBS. Rien ne s'y télécharge depuis Internet : on y range ce qui est déjà sur l'ordinateur, on l'active ou on le désactive.

La fenêtre a cinq onglets.

OngletCe qu'on y fait
Plugins audioVoir les effets CLAP et VST3 installés, les désactiver, savoir où ils servent
ShadersRanger ses shaders (filtres d'image) pour les reprendre partout
ScriptsVoir les scripts d'automatisation installés, les activer
Panneaux webOuvrir ou fermer les pages web du projet
Outils fournisRetrouver les programmes livrés avec RegieWave et leur notice

Plugins audio#

La liste montre chaque fichier de plugin trouvé dans les dossiers de plugins de l'ordinateur (voir Le son et ses effets) : son nom, son format (CLAP ou VST3), son éditeur, sa version, son dossier (bouton 📂), les effets qu'il contient et où il sert dans le projet (« Direct : entrée « Micro » », « Montage « Émission » : piste « Voix » »…).

  • Décocher un plugin : il n'est plus chargé du tout sur cet ordinateur. Il disparaît de la liste + Ajouter un plugin ; là où il servait, le son passe sans lui (une ligne orange le signale, avec un bouton Extensions…). Ses réglages restent dans le projet.
  • Recocher : il est relu et se remet en marche là où il sert, sans rien refaire.
  • ↻ Chercher à nouveau après avoir installé ou retiré un plugin.
  • Dossiers des plugins ouvre les dossiers où RegieWave les cherche.

Ce choix vaut pour cet ordinateur, pas pour le projet : un projet envoyé à quelqu'un d'autre garde ses plugins.

En bas, Utilisés par le projet, absents de cet ordinateur liste les plugins d'un projet venu d'ailleurs qui ne sont pas installés ici : le son passe sans eux tant qu'ils ne sont pas installés.

Un plugin tourne à l'intérieur de RegieWave : s'il est défaillant, il peut faire fermer RegieWave. Si cela arrive pendant sa lecture (au moment où RegieWave cherche les plugins), il est désactivé tout seul au lancement suivant, et la fenêtre Extensions s'ouvre pour le dire. Recochez-le pour l'essayer de nouveau. Un plugin qui pose problème plus tard (pendant le son) se désactive à la main, ici.

Shaders#

Une bibliothèque de shaders (les filtres d'image de l'extension « User-defined shader » d'OBS, ou ceux de Shadertoy), pour toutes les sources et tous les projets de cet ordinateur.

  • + Ajouter un shader… range une copie d'un fichier .shader, .effect, .hlsl, .glsl, .frag, .fs ou .txt.
  • Depuis une source : Retouche → Shader personnalisé → Garder dans la bibliothèque…, donnez un nom, Garder.
  • Chaque shader est vérifié : ✔ OBS ou ✔ Shadertoy s'il est compris, ✖ refusé avec la ligne qui pose problème sinon.
  • Les shaders cochés se trouvent dans Retouche → Shader personnalisé → Exemples → Ma bibliothèque. Décocher le laisse rangé sans le proposer.
  • Retirer supprime la copie rangée (après confirmation). Les sources qui l'utilisent gardent leur code : il est dans le projet.
  • 📂 Ouvrir le dossier montre les fichiers ; ↻ Relire après y avoir changé quelque chose.

Voir Shader personnalisé.

Scripts#

Les scripts enchaînent des commandes de RegieWave (changer de scène, lancer l'enregistrement, attendre, répéter…) sans programme : seulement les commandes qu'ils déclarent. Ils s'installent et se lancent dans le gestionnaire de scripts (bouton Ouvrir le gestionnaire de scripts ; Python 3.10 ou plus nécessaire).

Ici, on voit chaque script installé, les commandes permises et le nombre d'étapes, et on l'active ou le désactive : un script décoché est refusé par le gestionnaire. Un fichier abîmé ou modifié à la main est signalé en orange ; le gestionnaire vérifie aussi son contenu avant de le lancer.

Panneaux web#

Les pages web du projet (flux d'activité, tableau de bord…), comme les docks d'OBS : cochée, sa fenêtre est ouverte. 🌐 Gérer les panneaux web… pour en ajouter ou en retirer (voir Régie).

Outils fournis#

Les programmes livrés avec RegieWave et lancés à part : télécommande et scripts, caméra du téléphone, commandes de jeu à l'écran, plugin Stream Deck. Pour chacun : Lire la notice et 📂 Ouvrir le dossier. La caméra du téléphone et les commandes de jeu se démarrent dans Régie → Outils.

Ce qui n'existe pas encore#

  • Des extensions qui ajoutent de nouvelles sortes de sources ou de filtres écrites par d'autres (comme les plugins d'OBS) : à venir, dans un cadre fermé qui ne peut ni lire vos fichiers ni aller sur Internet sans votre accord.
  • Un catalogue en ligne d'extensions à télécharger.
